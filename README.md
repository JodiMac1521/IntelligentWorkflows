## Platform Overview

Work Simplr evolved from a talent marketplace into the operational backbone for AI-enabled project work - connecting vetted student talent to real business outcomes through the proprietary SprintWork methodology.

### SprintTrack Scoping Model

The scoping model is a compounding data asset with 6 layers:

- **L0 - Service Domains** (3): Research Services, User Testing, Data Organization
- **L1 - Project Categories** (24): Specific project types within each domain
- **L2 - Task Phases** (6 per domain): Sequential execution stages
- **L3 - Atomic Tasks** (55): Unit-level work items with calibrated time estimates
- **L4 - NACE Competency Map** (8): Career-readiness skill mapping per task
- **L5 - Credential Engine** (9): LinkedIn badges earned through task completion

### Key Metrics

- 5,000+ projects completed
- 98% completion rate
- 89% scope accuracy
- AI edit rate: 15% (down from 40%)

## Architecture

The AI Scoping Agent classifies client requests, matches them to the 55-task library, calculates scaled time estimates, and generates a priced Statement of Work in minutes.
